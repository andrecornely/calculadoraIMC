# 🧮 Calculadora de IMC

Projeto desenvolvido para praticar **JavaScript**, com foco em lógica de programação, manipulação do DOM e interação com formulários.

A aplicação permite inserir peso e altura, calcula automaticamente o **Índice de Massa Corporal (IMC)** e apresenta a classificação correspondente.

## 🚀 Funcionalidades

* Cálculo automático do IMC
* Classificação do resultado
* Validação dos campos de entrada
* Suporte para valores decimais
* Atualização dinâmica do resultado através do JavaScript
* Interface responsiva e simples
* Link para mais informações sobre IMC

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura da aplicação
* **CSS3** — Estilização e layout
* **JavaScript** — Cálculos, lógica e manipulação do DOM
* **Font Awesome** — Ícones
* **Google Fonts** — Fonte Poppins

## 📊 Classificação do IMC

| IMC            | Classificação      |
| -------------- | ------------------ |
| Abaixo de 18,5 | Abaixo do peso     |
| 18,5 – 24,9    | Peso normal        |
| 25 – 29,9      | Sobrepeso          |
| 30 – 34,9      | Obesidade grau I   |
| 35 – 39,9      | Obesidade grau II  |
| 40 ou mais     | Obesidade grau III |
